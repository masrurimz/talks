# Prompt untuk Generate Detailed Deck

## Instruksi untuk NotebookLM

Buat deck **Slide Detailed** untuk materi:

**Production Line Ops — Companion App untuk GinaV2**  
**Pilot bersama PT MAS Precast · 5 Agustus 2026**

### Pengaturan
- **Format**: Slide Detailed (informatif; handout/referensi).
- **Bahasa**: Indonesia.
- **Panjang**: target **16–18 slide**.

### Sifat — PENTING
- **Bukan penjualan.** Pilot/riset bersama mitra. Tidak ada arus "problem → solusi → nilai".
- Korelasi kecepatan/kualitas = **yang diteliti bareng**, bukan janji.
- **Penempatan orang→mesin/PIN TIDAK di slide** — dilakukan saat sesi.

### Urutan narasi
1. Sampul + agenda 90 menit.
2. **Tiga peran sederhana** + tugas per peran (referensi).
3. Login & bahasa.
4. **Diagram big-picture process** (mesin → sensor+app → riset bareng).
5. Yang diteliti bareng.
6. Prinsip data jujur.
7. Alur satu hari + arti tiap langkah.
8. Mengapa install + checklist install + Vysor.
9. Referensi layar operator/supervisor/admin.
10. Aturan + stuck cases + transisi live demo (penempatan bareng).

### Gaya
- Lebih padat dari presenter, tetap bullet/tabel — bukan esai.
- Bahasa lantai; tanpa jargon.
- Cocok dicetak/dibuka saat praktik.
- Tidak menulis PIN.

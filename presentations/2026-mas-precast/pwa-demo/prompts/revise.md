# Prompt Revisi Deck

## Instruksi untuk NotebookLM

Revisi deck **PWA Demo MAS Precast** dengan patokan berikut.

### Sifat — wajib
- **Pilot/riset bersama mitra, BUKAN penjualan.**
- Potong segala arus "problem → solusi → nilai/ROI".
- Korelasi kecepatan/kualitas = yang diteliti bareng, bukan janji hasil.

### Urutan — pertahankan
1. **Peran sederhana dulu** (Operator/Supervisor/Admin + tugas dasar)
2. Baru **diagram big-picture process** (mesin → sensor+app → riset bareng)
3. Alur satu hari
4. Install Android Chrome + Vysor
5. Transisi live demo

### Wajib ada
- Tiga peran sederhana di muka
- Diagram big-picture process
- Diagram alur satu hari
- Slide install PWA
- Pengingat: kosong boleh, menebak tidak
- Transisi: penempatan dilakukan bareng saat sesi

### Potong/perbaiki jika muncul
- Penempatan orang→mesin / PIN di slide (pindahkan ke "dilakukan saat sesi")
- Arsitektur, database, tech stack, jargon
- Feature tour panjang
- Chart/analisis seolah tersedia hari ini
- Fokus berlebih ke iOS

### Cek kualitas
- Presenter ~14–16 slide, bicara 10–15 menit
- Detailed berguna sebagai handout saat praktik
- Satu slide satu gagasan

### Sumber kebenaran
Utamakan `brief.md`, `structure.md`, outline sesuai (`presenter.md`/`detailed.md`), lalu referensi.

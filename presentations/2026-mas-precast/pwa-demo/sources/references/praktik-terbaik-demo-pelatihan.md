# Praktik Terbaik Demo & Pelatihan App (ringkas)

Disarikan untuk sesi MAS Precast (frontline, non-tech-savvy, 90 menit). Sumber inspirasi: praktik software demo modern + pelatihan pekerja frontline/mobile.

## 1. Big picture sebelum klik
- Jangan mulai dari menu.
- Tunjukkan dulu masalah bisnis + diagram companion GinaV2.
- Baru masuk install dan jari di layar.

## 2. Show then practice
- Satu cerita utuh di satu mesin (Pipe No.5) sambil peserta menonton.
- Baru praktik per peran/mesin.
- Pola: *saya tunjukkan → Anda coba dengan checklist*.

## 3. Latih di perangkat nyata
- Frontline belajar di HP kerja, bukan hanya melihat proyektor.
- Install PWA ke Home Screen adalah bagian pelatihan, bukan afterthought.
- Vysor dipakai agar HP presenter terlihat semua orang.

## 4. Role-based, bukan feature tour
- Ajarkan “tugas saya hari ini”, bukan 20 fitur.
- SPV ≠ Operator ≠ Admin — checklist berbeda.
- Owner (Sylvia) diajak di level mengapa bisnis; SPV/Op di level ketukan.

## 5. Satu alur, target kecil
- Demo dengan target kecil supaya “Needs you / target reached” muncul cepat.
- Hindari sidetrack fitur admin yang dalam saat blok demo utama.

## 6. Bahasa lantai + UI Indonesia
- Hindari jargon data science di slide.
- Paksa bahasa app tetap Indonesia selama sesi.

## 7. Aturan ruang yang menenangkan
- HP peserta diam saat blok show.
- Macet → angkat tangan (jangan lawan HP lima menit).
- Kosong boleh, menebak tidak — budaya data lebih penting dari form penuh.

## 8. Yang tidak dilakukan di intro
- Feature laundry list
- Chart analisis yang belum jadi fokus hari ini
- Arsitektur / tech stack
- Membagikan PIN di slide publik

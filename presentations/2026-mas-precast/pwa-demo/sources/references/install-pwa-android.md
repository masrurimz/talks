# Install PWA — Android Chrome (+ catatan Vysor)

## Tujuan
Peserta tidak hanya *melihat* app di browser, tetapi **memasang** ke Home Screen agar menjadi kebiasaan kerja di lantai.

## Mengapa Home Screen
- Lebih cepat dibuka saat tangan buru-buru / berdebu
- Terasa seperti app kerja, bukan tab sekali pakai
- Konsisten dengan pelatihan frontline: latih di perangkat yang benar-benar dipakai

## Langkah (Android + Chrome) — jalur utama sesi
1. Pastikan HP memakai **Chrome**.
2. Buka URL aplikasi lewat **HTTPS** (wajib untuk install PWA).
3. Ketuk menu **⋮**.
4. Pilih **Install app** atau **Tambahkan ke layar utama** / **Add to Home Screen**.
5. Konfirmasi.
6. Tutup tab browser; buka lagi dari **ikon di Home Screen**.
7. Pastikan bahasa = **Indonesia**.
8. Login dengan PIN 4 digit dari kartu.

## Setup presenter
- HP Android terhubung ke Mac dengan **Vysor**.
- Proyeksikan jendela Vysor saat langkah install dan live demo.
- Ucapkan setiap ketukan sekali; jangan terlalu cepat.

## FAQ singkat (jangan jadi jalur utama slide)
- **iPhone:** biasanya Safari → Share → Add to Home Screen; Chrome iOS tidak setara untuk install PWA.
- Sesi ini fokus **Android** karena itu perangkat yang dipakai demo dan praktik.
